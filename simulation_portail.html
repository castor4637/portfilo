TP Îlot Portail

Modélisation cinématique et simulation d’un portail motorisé

Kalvin Margat · Florian Lheureux · Maxence Olivier · Frédéric Maureau Antchouey

1. Objectif

Le portail est actionné par un bras moteur (1) relié à une biellette de poussée (2) qui entraîne le vantail (3) en rotation autour du bâti (0). L’objectif du TP est de déterminer la relation entre l’angle du bras moteur θm et l’angle d’ouverture du vantail θv, puis de comparer le modèle théorique aux mesures réelles.

2. Simulation interactive

Fais varier l’angle d’ouverture du vantail et observe la position du bras moteur calculée à partir de la fermeture géométrique. Les paramètres sont modifiables.

θv = 0° θm = –° Δθm = –° β = –°

3. Graphe de liaisons

Quatre solides : bâti 0, bras moteur 1, biellette 2 et vantail 3. Les quatre liaisons sont des pivots d’axe (z₀) :

LiaisonTypePointParamètre
0 – 1PivotAθm
1 – 2PivotB–
2 – 3PivotC–
3 – 0PivotOθv

Le mécanisme est une chaîne fermée plane de type quadrilatère articulé (θm = entrée, θv = sortie, β = angle intermédiaire de la biellette).

4. Fermeture géométrique

OA + AB + BC + CO = 0 −a·x₀ − b·y₀ + l·x₁ + l·x₂ − c·x₃ + d·y₃ = 0

Projection dans la base 0 :

/x₀ : −a + l·cos(θm) + l·cos(β) − c·cos(θv) − d·sin(θv) = 0 /y₀ : −b + l·sin(θm) + l·sin(β) − c·sin(θv) + d·cos(θv) = 0

5. Élimination de β

On isole l·cos(β) et l·sin(β), on élève au carré et on additionne (cos²+sin² = 1) :

l² = (a − l·cos(θm) + c·cos(θv) + d·sin(θv))² + (b − l·sin(θm) + c·sin(θv) − d·cos(θv))²

Pour un θv donné, on pose Q = (Qx, Qy) avec Qx = a + c·cos θv + d·sin θv et Qy = b + c·sin θv − d·cos θv. L’équation devient |l·u(θm) − Q| = l, dont la solution est :

θm = atan2(Qy, Qx) + arccos( ‖Q‖ / 2l )

Cette forme explicite est celle utilisée par la simulation ci-dessus (branche « bras moteur vers le haut », celle du portail réel).

Valeurs : a = 100 mm, b = 150 mm, c = 250 mm, d = 20 mm, l = 280 mm.

Sur la diapositive, c est indiqué à 150 mm, mais le tableur de la « courbe attendue » utilise c = 0,25 m. Avec c = 150 mm, le modèle donne θm ≈ 123° à θv = 90° ; avec c = 250 mm, θm ≈ 115°, ce qui est cohérent avec les 117° mesurés. À vérifier sur le portail réel.

6. Résultats et comparaison

Courbe attendue (théorique)

Calculée dans le tableur à partir de l’équation de l² ; la courbe est croissante et quasi linéaire jusqu’à environ 96 en fin de course.

Courbe réelle (mesure)

Le relevé des angles montre une évolution quasi linéaire jusqu’à une position finale d’environ 117° pour le moteur et 90° pour le vantail.

Courbe simulée

La première simulation (tableur) affichait des valeurs aberrantes de l’ordre de 10³², signe d’un problème de formule ou d’unités (mm mélangés à des m). La simulation de cette page résout l’équation de fermeture directement, ce qui évite ce problème.

Comparaison

Valeur finale simulée : –° pour θm, contre ≈ 117° mesuré. L’écart restant s’explique probablement par les jeux, les tolérances de montage et la précision du capteur.

7. Conclusion

Le modèle géométrique par fermeture de chaîne reproduit correctement le comportement du portail : la relation entre θm et θv est quasi linéaire sur la plage d’ouverture 0–90°, comme sur les mesures. La principale source d’écart est la valeur des paramètres (en particulier c) et les imperfections réelles du mécanisme. Pour aller plus loin, on pourrait ajuster les paramètres par optimisation sur les mesures et calculer l’effort moteur.
